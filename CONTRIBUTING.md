# Contributing to the Bruce Constraint‑Aware Decision Module (BCADM)

Thank you for your interest in contributing to BCADM. This project aims to
advance constraint‑aware agent architecture, safety‑contract reasoning, and
decision‑module research. High‑quality contributions are welcome and appreciated.

---

## How to Contribute

### 1. Reporting Issues
If you encounter a bug, unexpected behavior, or design inconsistency:
- Open an Issue with a clear description.
- Include reproduction steps when possible.
- Attach logs, traces, or simulation output if relevant.

### 2. Suggesting Enhancements
Feature proposals should include:
- The problem or limitation being addressed.
- A clear description of the proposed solution.
- Any architectural considerations or safety‑contract implications.

### 3. Submitting Pull Requests
Before opening a PR:
- Ensure your code follows the project’s structure and style.
- Include meaningful commit messages.
- Add tests when applicable.
- Document new functions, modules, or behaviors.

PRs should be focused and scoped. Large changes may require discussion first.

---

## Development Environment

BCADM uses:
- Python 3.x
- Simulation modules defined in `bruce_simulation.py`
- GitHub Actions for basic CI

Please ensure your environment matches the expected versions and dependencies.

---

## Code Style

- Use clear, descriptive variable names.
- Avoid unnecessary complexity.
- Document safety‑contract logic thoroughly.
- Keep functions small and purpose‑driven.
- Follow existing patterns in the repository.

---

## Community Standards

This project follows the **CODE_OF_CONDUCT.md** included in the repository.
Respectful collaboration is expected.
